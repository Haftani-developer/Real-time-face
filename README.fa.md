# 🛰️ FaceSentinel

**تشخیص، ردیابی و شناسایی چهره به‌صورت لحظه‌ای، فقط با OpenCV.**
بدون dlib، بدون TensorFlow و PyTorch؛ فقط دو مدل سبک ONNX.

[English](README.md)

## ✨ امکانات

- 🎯 **تشخیص مدرن چهره** با YuNet همراه با ۵ نقطه‌ی کلیدی (چشم‌ها، بینی، دهان)
- 🧬 **شناسایی با یادگیری عمیق** با SFace و مقایسه‌ی کسینوسی
- 🧵 **هویت پایدار:** ردیاب با رأی‌گیری، تا نام‌ها چشمک نزنند
- ⚡ **سریع:** خواندن فریم در ترد جدا، شناسایی فقط وقتی لازم است، گزینه‌ی `--scale`
- 🙈 **حالت حریم خصوصی:** محو یا پیکسلی کردن چهره‌ی افراد ناشناس به‌صورت زنده
- 🗒️ **لاگ حضور و غیاب** در CSV (سازگار با اکسل و نام فارسی)
- 📸 **ثبت‌نام هوشمند:** فقط نمونه‌های باکیفیت را ذخیره می‌کند
- 🌍 **نمایش نام فارسی** روی تصویر (با نصب `unicode`)

## 🚀 شروع سریع

</div>

```bash
git clone https://github.com/YOUR_USER/facesentinel.git
cd facesentinel
python -m venv .venv
.venv\Scripts\activate          # لینوکس/مک: source .venv/bin/activate
pip install -e ".[unicode]"     # unicode برای نمایش نام فارسی

facesentinel models                         # دانلود دو مدل (یک‌بار)
facesentinel enroll --name "سارا" --mirror  # ثبت چهره با وبکم
facesentinel live --mirror --log            # شناسایی زنده + ثبت حضور
```

## 🧰 دستورها

| دستور | کار |
|---|---|
| `models` | دانلود مدل‌ها |
| `enroll --name N` | افزودن فرد با دوربین یا `--images پوشه/` |
| `live` | شناسایی زنده از وبکم، فایل ویدیو یا RTSP |
| `image عکس.jpg` | تحلیل یک عکس (`--json` برای خروجی ماشینی) |
| `video in.mp4 -o out.mp4` | پردازش ویدیو |
| `list` و `remove --name N` | مدیریت دیتابیس |
| `bench عکس.jpg` | سنجش سرعت روی سیستم خودتان |

**کلیدها در حالت زنده:** `q` خروج · `p` حریم خصوصی · `l` نقاط چهره · `h` پنل · `s` عکس · `r` ضبط · `Space` توقف

## 🔤 نمایش نام فارسی

OpenCV نمی‌تواند حروف فارسی را رسم کند؛ پس با Pillow نمایش داده می‌شود:

pip install -e ".[unicode]"

## 🔒 حریم خصوصی و قانون

اطلاعات چهره **داده‌ی بیومتریک** است.

- فقط افرادی را ثبت کنید که **رضایت داده‌اند** و به افراد اطلاع دهید که دوربین چهره‌ها را شناسایی می‌کند.
- رعایت قوانین محل خودتان بر عهده‌ی شماست.
- پوشه‌ی `data/` و فایل‌های `*.npz` را **هرگز در گیت‌هاب نگذارید** (در `.gitignore` هست).
- تشخیص چهره خطا دارد؛ تنها مبنای تصمیم‌های مهم درباره‌ی افراد قرار ندهید.

## 🎛️ تنظیم دقت

- **غریبه‌ها شناسایی می‌شوند:** `--threshold` را بالاتر ببرید (مثلاً `0.45`).
- **آشناها ناشناس نشان داده می‌شوند:** مقدار را کمی پایین بیاورید و در نور واقعی محیط، نمونه‌ی بیشتری ثبت کنید.
- **FPS پایین:** `--scale 0.5` یا `--rec-every 30` را امتحان کنید.
